Even though it's called a *Studio*, Elmarath is a solo game development project. The only game it is currently developing is *Hermod's Ride*.

<!-- truncate -->

![Hermod's Ride](./hermods-ride.jpeg)

Hermod's Ride is a top-down, medieval slasher, multiplayer arena game.

It is also the testing ground for every plugin documented on this site: each system starts as something the game needs, and only later becomes a standalone tool.
